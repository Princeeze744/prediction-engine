# QuantSport AI Web — Product Experience Prototype

Portfolio-grade responsive Next.js foundation for the new QuantSport AI publishing platform.

## Run
npm install
npm run dev

Open http://localhost:3000

## Included
- Cinematic landing page
- Today's Intelligence
- Football / Basketball / Tennis routes
- Match Intelligence / Quant Map
- Prospective Track Record
- Private Command Center interaction: Ingest → Analyse → Review → Publish
- Mobile navigation and responsive design

## Important
Current match content is clearly a UI prototype/sample layer. Production integration must connect the frozen QuantSport v10.7 Python engines through a FastAPI service and persisted publication database. Do not rewrite or tune model mathematics in the frontend.
